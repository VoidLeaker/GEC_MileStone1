Martin Ruzzle Z. Imperial
Milestone 1 Patch 0.0.0 - Patch 0.0.4 and October 9th 2026
--------------------------------

New Functionality
-----------------

- Can create a custom animated sprite which has a texture, number of frames, sprite width and height, and a time between frames (speed)
- This sprite allows the first frame to be set, as well as having a function to update the intRect based on which sprite/frame to display

Code Additions
--------------

- Calculating the FPS over a second, and then displaying this through the ImGUI
- Added multiple buttons to support the multiple animation sets, so when pressing the buttons changes different animations
  - Default animation is idle

Tests
-----

- Tested the sprite with a number of textures and animations
  - Error: The dead animation is clipping with the hands.
  - Fixes: Removed the dead animation as I already supported multiple animation sets.

Notes
